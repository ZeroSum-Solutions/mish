# Loop School | Coding lessons

Use this owned example as a starting point for a coding-school landing page.

## Structure

Course introduction; fixed interactive lesson; curriculum; learning FAQ; course enquiry.

## Interaction

Run a fixed function with selectable argument; native FAQ; entry reveals. All selectors have pressed state or a native accessible control. Forms are local demonstrations with visible feedback, not live submission endpoints.

## Adaptation

Read `example.html` for the working layout. Copy `fonts.css` and its local `assets/` folder with the artifact so the font URLs resolve. Keep `assets/OFL.txt` with the fonts. Use the existing original vector artwork or replace it with assets the project owns. Do not fetch images, videos, fonts, scripts or reference-site content.

Write fresh project copy and verify real product claims before publishing. Preserve responsive layout, visible focus, keyboard access, reduced-motion support, no-script content and print output. Keep primary actions attached to real sections or a clearly labelled demo form.
