Variant fixture — same brief as rich.txt, but reviewer names are explicitly supplied.

Kept SEPARATE from rich.txt on purpose: rich.txt's reviews are anonymous ("one wore the field
jacket...; another says...") and must stay that way, so it keeps proving the anonymous case
(no invented attribution — a null name renders no attribution line at all, not even a neutral
"Verified buyer" label, since that would itself assert an unverified fact the brief never gave).
This file is the positive-path counterpart: when a brief DOES name its reviewers, those real
names are allowed through — deterministicAttributionFlags only flags a name that is NOT a
substring of the brief, never a name that is.
